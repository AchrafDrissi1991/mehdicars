Bitte überarbeite den Anfrage-Funnel als kompakten, modernen 4-Schritte-Prozess.

Der Funnel soll inspiriert sein von den gezeigten Screenshots:
- große klare Überschrift
- heller Funnel-Bereich
- viel Weißraum
- große Inputs / Selects / Auswahlflächen
- Step-by-Step Navigation
- unten: Zurück / Schritt X von 4 / Weiter
- kein langes klassisches Formular

Wichtig:
Unsere Farben bleiben:
- Royal Blue
- Dunkelblau
- Schwarz/Graphit
- Weiß
- Hellgrau
- neutrale Grautöne

Bitte KEIN Gold, KEIN Bronze, KEIN Braun, KEIN Beige verwenden.

Farbsystem für den Funnel:
- Primary: #2F6FED
- Primary Hover: #255ED0
- Primary Active: #1E4EAD
- Background: #F8FAFC oder #F1F5F9
- Surface: #FFFFFF
- Text: #111827
- Body Text: #4B5563
- Muted Text: #6B7280
- Border: #E5E7EB
- Strong Border: #CBD5E1
- Hover Background: #EFF6FF
- Selected Background: #E0ECFF
- Selected Text: #1E4EAD
- Focus Shadow: 0 0 0 3px rgba(47,111,237,0.16)

Der Funnel besteht aus 4 Schritten:

==================================================
STEP 1 / 4: Fahrzeugmarke und Modell
==================================================

Ziel:
Der Kunde gibt an, welche Automarke er sucht. Es soll nicht nur eine kleine Auswahl von Marken geben, sondern eine vollständige durchsuchbare Automarkenliste.

Titel FR:
Quelle marque recherchez-vous ?

Titel DE:
Welche Automarke suchen Sie?

Felder:
1. Automarke Select
2. Modell Text Input optional
3. Optional: Quick-Chips für beliebte Marken

FR Labels:
- Marque
- Modèle optionnel

DE Labels:
- Automarke
- Modell optional

UI:
- Verwende Ant Design Select.
- Der Select muss searchable sein.
- Der Kunde soll tippen können, um Marken schnell zu finden.
- Der Select soll groß und gut klickbar sein.
- Placeholder FR: Sélectionnez une marque
- Placeholder DE: Marke auswählen
- Modellfeld darunter als normales Input.
- Modell bleibt optional.
- Optional unter dem Select kleine Quick-Chips für beliebte Marken:
  Audi, BMW, Mercedes-Benz, Volkswagen, Porsche, Tesla
- Wenn ein Quick-Chip geklickt wird, wird der Select-Wert automatisch gesetzt.

Wichtig:
Bitte die festen 6 Marken-Cards entfernen oder nur noch als kleine Quick-Chips verwenden.
Die vollständige Markenauswahl muss über den Select möglich sein.

Ant Design Select Beispiel:

<Select
  showSearch
  size="large"
  placeholder={language === "fr" ? "Sélectionnez une marque" : "Marke auswählen"}
  options={brandOptions}
  value={formData.brand}
  onChange={(value) => updateFormData({ brand: value })}
  filterOption={(input, option) =>
    String(option?.label ?? "")
      .toLowerCase()
      .includes(input.toLowerCase())
  }
/>

==================================================
STEP 2 / 4: Fahrzeugkriterien
==================================================

Ziel:
Der Kunde gibt die wichtigsten Suchkriterien an.

Titel FR:
Quel type de véhicule ?

Titel DE:
Welches Fahrzeug suchen Sie genau?

Felder:
1. Fahrzeugtyp / Modellwunsch als Freitext
2. Baujahr ab
3. Kilometer maximal
4. Budget

FR Labels:
- Type de véhicule ou modèle recherché
- Année minimum
- Kilométrage maximum
- Votre budget

DE Labels:
- Fahrzeugtyp oder Modellwunsch
- Baujahr ab
- Maximale Kilometer
- Budget

UI:
- Oben ein großes Input-Feld für Fahrzeugtyp / Modellwunsch.
- Darunter drei Slider:
  1. Baujahr ab
  2. Kilometer maximal
  3. Budget
- Werte jeweils rechts neben dem Label anzeigen.
- Slider modern, sauber und gut bedienbar.

Empfohlene Slider-Werte:
- Baujahr: 2005 bis aktuelles Jahr
- Kilometer: 0 bis 250.000 km
- Budget: 5.000 € bis 100.000 €

Formatierung:
- Kilometer mit Leerzeichen formatieren, z. B. 55 000 km
- Budget als Euro formatieren, z. B. 70 000 €
- Baujahr als Jahr, z. B. 2023

Slider Design:
- active track #2F6FED
- handle #2F6FED
- rail #CBD5E1
- hover/focus mit Royal Blue
- keine warmen Farben

Validierung:
- Step 2 darf weitergehen, wenn mindestens Fahrzeugtyp/Modellwunsch oder Budget vorhanden ist.
- Baujahr und Kilometer sind optional, aber empfohlen.

==================================================
Technische Umsetzung
==================================================

Bitte den Funnel so bauen, dass er später einfach erweitert werden kann.

Empfehlung:
- Steps als Konfiguration definieren.
- FormData zentral im State speichern.
- updateFormData helper verwenden.
- Keine Steps hart und unübersichtlich verdrahten.
- TypeScript sauber verwenden.
- Validierung pro Step in einer Funktion bündeln.
- Komponenten aufteilen:

components/funnel/LeadFunnel.tsx
components/funnel/FunnelNavigation.tsx
components/funnel/StepBrand.tsx
components/funnel/StepCriteria.tsx
components/funnel/StepTechnicalPreferences.tsx
components/funnel/StepContact.tsx
components/funnel/SuccessStep.tsx
data/carBrands.ts
types/lead.ts

Beispiel Funktionen:
- updateFormData(partialData)
- canGoNext(currentStep, formData)
- handleNext()
- handlePrevious()
- handleSubmit()

==================================================
Wichtige Design-Regeln
==================================================

Bitte unbedingt beachten:
- Kein Gold.
- Kein Bronze.
- Kein Braun.
- Kein Beige.
- Keine warmen CTA-Farben.
- Keine gelben Buttons.
- Keine gelben Badges.
- Keine WhatsApp Buttons.
- Keine festen 6 Marken-Cards als einzige Auswahl.
- Automarke muss über vollständigen Searchable Select auswählbar sein.
- Der Funnel soll kurz wirken: maximal 4 Schritte.
- Mobile Darstellung muss sauber sein.
- Inputs und Auswahlkarten müssen groß genug für Touch sein.
- Selected States müssen klar sichtbar sein.
- Farben müssen zum bestehenden Royal-Blue/Dark/White/Gray Design passen.
